🛡️ PhishyGuard - Phishing Detection Dashboard
🚀 Overview
PhishyGuard is an intelligent phishing detection system that uses machine learning to identify malicious URLs and websites in real-time. It helps users detect phishing attacks and protects them from credential theft, financial fraud, and other cyber threats.
Phishing is one of the most common cyber attacks where attackers create fake websites to steal sensitive information such as usernames, passwords, and banking details. PhishyGuard provides a smart and efficient solution to detect such threats automatically.

🎯 Features
🔍 Real-time URL phishing detection
🤖 Machine Learning-based classification
📊 Interactive dashboard for visualization
⚡ Fast and efficient prediction system
🌐 Simple and user-friendly interface

🧠 How It Works
User enters a URL into the system
The application extracts important features from the URL
The trained machine learning model analyzes the features
The system predicts whether the URL is:
✅ Legitimate
❌ Phishing

The result is displayed instantly on the dashboard
